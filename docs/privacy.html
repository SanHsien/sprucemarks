本頁面為公開、靜態之隱私權政策（不需登入、不需執行 JavaScript，相容 Google Chrome Web Store 審查機制）。Markdown 原文可於 GitHub 檢視。

1. 核心隱私承諾 / Core Commitment

Sprucemarks 堅持零收集、零追蹤、零外部伺服器連線原則：

  • 無自有伺服器：本擴充功能沒有任何後端伺服器，不會將任何資料傳輸給開發者或第三方。
  • 無分析與追蹤：不包含 Google Analytics、遙測（Telemetry）、廣告代碼或任何第三方追蹤腳本。
  • 不販售使用者資料：我們絕不販售、出租、交換或以任何形式提供使用者資料。

2. 我們處理的資料 / Data We Process

本擴充功能僅於您的本機瀏覽器環境中處理下列資料：

  • 書籤資訊（Bookmarks）：本機讀取書籤的標題（Title）、網址（URL）、建立時間與階層結構，用於依據您所選擇的規則在瀏覽器內部進行排序。排序演算法 100% 在本機運行。
  • 排序偏好（Settings & Preferences）：您在選項頁面中設定的排序標準（標題/日期/網址、遞增/遞減、排除目錄、深淺色主題），儲存於本機 chrome.storage.local。

3. 權限宣告用途 / Permissions Justification

權限 (Permission) 用途說明 (Justification)
bookmarks 讀取書籤標題、日期、網址進行排序比對，並在必要時調用 move API 調整書籤於資料夾內的顯示順序。所有資料保留於本機。
storage 於本機儲存使用者的排序偏好規則、排除資料夾設定與外觀主題。不儲存任何個人隱私身分。

4. 第三方資料共享 / Third-Party Data Sharing

本擴充功能完全不與任何第三方共享資料。本軟體無任何網路請求權限，無法連線至外部網際網路。
